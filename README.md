# Pokemon Love temporary mobile playtest

Godot browser export, version 0.2.2-mobile-web.20261107. Turn a phone sideways and use the translucent controls over the game. First loading downloads about 101 MiB before browser compression/cache.

This repository contains the playable browser export. The original Godot project, native saves and QA instrumentation are not published here. No analytics or remote save service is added. Browser saves stay on the same device, browser and site address.

Real iPhone/Android audio, performance and long-term save testing remain pending. The game has passed desktop Chromium/WebKit touch-layout and tutorial battle/capture/save/reload checks.

GitHub Pages serves the main branch at its root. `.nojekyll` preserves exported filenames. To end the temporary playtest, disable Pages in repository Settings > Pages. Hosting is not automatically scheduled to expire.
